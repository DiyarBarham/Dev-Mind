# Behavioral scenarios

`cases.json` contains ten easy and ten difficult raw requests and starting files.
These are fictional projects and contain no real credentials. Evaluate each in
its own directory with the installed skill. Do not execute recorded deployment
commands or access external systems. Write the agent's final response to
`response.md` beside the project. Prepare a new fixture tree with
`python3 tests/scenarios/prepare.py /tmp/dev-mind-scenarios-new`.
Keep expected results separate from the agent
performing the task, then inspect actual files and changes against the rubric.

The scenario runner is a human or agent, not a deterministic unit test. A passing
artifact check alone cannot establish faithful interpretation or host discovery.
See the dated evaluation report for the exact method, outputs, and limitations.
